[![Go Version](https://img.shields.io/badge/Go-1.26+-00ADD8?style=flat&logo=go)](https://golang.org)

یه دانلودر چندنخی و خفن که از **HTTP/HTTPS**، **FTP/FTPS**، **SFTP**، **Metalink**، **پروکسی ضبط MITM**، **اتصالات پروکسی**، **ادامه دانلود هوشمند**، **رابط JSON-RPC**، **ابزار کامل پشتیبان‌گیری از وب‌سایت**، **پخش زنده HLS**، **سیستم صف اولویت‌دار** و **پردازش‌های پس از دانلود** پشتیبانی میکنه. همه‌چیزش برای سرعت و اطمینان بالا طراحی شده.

---

## 🎉 تازه‌های نسخه ۳.۳.۲

توی نسخه جدید کلی قابلیت جذاب اضافه شده که کار با هد رو خیلی راحت‌تر و حرفه‌ای‌تر میکنه:

### ✨ قابلیت‌های اصلی جدید
- 📺 **پشتیبانی از پخش زنده HLS** - می‌تونی استریم‌های زنده و فیلم‌های M3U8 رو با خیال راحت دانلود کنی (با FFmpeg یا خود گو)
- 📋 **سیستم صف اولویت‌دار** - دانلودها رو بر اساس اولویت مرتب کن و بذار صف
- 🔄 **زمان‌بندی پهنای باند** - دانلود رو توی بازه‌های زمانی خاص مثل شب‌ها انجام بده
- 📢 **اعلان‌های چندکاناله** - از تلگرام، دیسکورد یا نوتیفیکیشن سیستمت با خبر بشو
- 🪞 **انتخاب هوشمند آینه** - سریع‌ترین آینه رو با پینگ خودکار انتخاب کن
- 🗜️ **پردازش خودکار** - بعد از دانلود، فایل رو اکسترکت کن، تغییر اسم بده یا جابجا کن
- 🧩 **حذف تکراری‌ها** - تشخیص و حذف خودکار لینک‌های تکراری
- 🎯 **بهینه‌سازی نخ بر اساس حجم** - تعداد نخ‌ها رو بر اساس حجم فایل تنظیم کن

### 🔧 بازطراحی کامل افزونه مرورگر
- 🍪 **مدیریت کامل کوکی‌ها** - دیدن، ویرایش، حذف، واردات و صادرات کوکی‌های هر سایت
- 🎯 **کوکی‌های مخصوص سایت** - خودکار کوکی‌های صفحه‌ای که توش هستی رو نشون میده
- 📋 **خروجی چندفرمتی** - کوکی‌ها رو به صورت هدر، JSON یا فرمت نت‌اسکیپ ذخیره کن
- 🔄 **واردات پیشرفته** - کوکی‌ها رو از JSON، نت‌اسکیپ یا رشته هدر وارد کن
- 🔍 **جستجوی کوکی** - کوکی‌ها رو با اسم یا مقدارشون پیدا کن
- ⚡ **پریست‌های سریع** - تنظیمات از پیش‌ساخته برای پروکسی‌های رایج
- 🏃 **بازگردانی خودکار** - پروکسی با هر بار اجرای مرورگر فعال میشه

### 🎯 به‌روزرسانی‌های پروکسی ضبط هوشمند
- 🧠 **تشخیص قوی‌تر** - امتیازدهی دقیق‌تر و استخراج لینک‌های پنهان
- 🔍 **اسکن بدنه** - بررسی عمیق HTML، JSON و جاوااسکریپت برای لینک‌های مخفی
- 📊 **سیگنال‌های پیشرفته** - امتیازدهی چندعاملی (مسیر، کوئری، هدرها، رفرر)
- 🎯 **بهبود داپلیکیت** - نرمال‌سازی هوشمند برای جلوگیری از تکراری‌ها
- 📝 **متادیتای غنی‌تر** - ذخیره متد، وضعیت، نوع محتوا و اطلاعات بیشتر

## ✨ امکانات کلی

### دانلودر اصلی
- 🧵 **دانلود چندنخی** - استفاده حداکثری از پهنای باند با بافر تطبیقی (۳۲ کیلوبایت تا ۴ مگابایت)
- 📡 **پروتکل‌های متنوع** - HTTP، HTTPS، FTP، FTPS، SFTP با پشتیبانی کامل از احراز هویت
- 🔄 **ادامه دانلود** - قطع و وصل کردن دانلودها بدون مشکل با فایل‌های جلسه
- 🕸️ **پشتیبانی از پروکسی** - پروکسی‌های SOCKS4، SOCKS5 و HTTP/HTTPS با احراز هویت
- 📁 **دانلود دسته‌ای** - دانلود از لیست فایل با پشتیبانی از کامنت‌گذاری
- 🕷️ **وب اسکرپینگ** - استخراج و دانلود لینک‌ها از صفحات وب با انتخاب تعاملی
- 🔍 **فیلتر پسوند** - فیلتر کردن دانلودها بر اساس پسوند فایل
- ⚡ **بافر تطبیقی** - بهینه‌سازی خودکار اندازه بافر بر اساس سرعت (۳۲KB تا ۴MB)
- 💾 **ذخیره جلسه** - ذخیره پیشرفت هر ۱۰ ثانیه و ادامه بعداً
- 🎨 **نوار پیشرفت زیبا** - بازخورد بصری لحظه‌ای با پیشرفت تک‌نخ
- 🌍 **چندسکویی** - ویندوز، لینوکس، مک، ARM64
- 🔐 **بررسی یکپارچگی** - تأیید SHA256، SHA1، MD5
- 📺 **پخش زنده HLS** - دانلود پلی‌لیست‌های M3U8 و سگمنت‌ها (با FFmpeg یا خالص گو)
- 📋 **صف اولویت‌دار** - دانلود آدرس‌ها با ترتیب اولویت‌بندی شده
- ⏰ **زمان‌بندی پهنای باند** - تنظیم بازه زمانی برای دانلود (مثلاً ۰۰:۰۰ تا ۰۶:۰۰)
- 📢 **اعلان‌ها** - اعلان تلگرام، دیسکورد و دسکتاپ در پایان یا شکست دانلود

### پروکسی ضبط MITM
- 🔒 **رهگیری HTTPS** - قابلیت کامل پروکسی مرد میانی با نصب خودکار گواهی
- 🎯 **تشخیص خودکار** - تشخیص خودکار ویدیو، موسیقی، تصویر، سند، آرشیو
- 🔍 **استخراج لینک پنهان** - اسکرپینگ HTML، JSON و جاوااسکریپت برای لینک‌های دفن شده
- 📊 **امتیازدهی اطمینان** - سیستم اطمینان ۰ تا ۱۰۰٪ با امتیازدهی چندعاملی
- 📝 **خروجی چندفرمتی** - ذخیره لینک‌ها در هر دو فرمت TXT و JSON
- 🔧 **پسوند سفارشی** - اضافه کردن پسوند دلخواه برای ضبط
- 🎯 **فیلتر دامنه** - تمرکز روی دامنه‌های خاص
- 📐 **فیلتر اندازه** - محدودیت حداقل و حداکثر اندازه فایل
- 🔄 **دانلود خودکار** - دانلود خودکار فایل‌های ضبط شده
- 🍪 **پشتیبانی از کوکی** - عبور کوکی‌ها از طریق پروکسی
- 🔐 **گواهی خودکار** - نصب خودکار گواهی CA (ویندوز، مک، لینوکس)
- 🧠 **حذف تکراری هوشمند** - پنجره ۱۰ دقیقه‌ای با نرمال‌سازی آدرس

### دانلود از JSON ضبط شده
- 📦 **دانلود دسته‌ای** - دانلود همه فایل‌های ضبط شده با یک دستور
- ⚡ **نخی هوشمند** - تنظیم خودکار تعداد نخ‌ها بر اساس حجم (۱ تا ۸ نخ)
- 🔄 **دانلود همزمان** - دانلود چند فایل به طور همزمان
- 📊 **پیشرفت یکپارچه** - پیگیری همه دانلودها در یک رابط زیبا
- 💾 **پشتیبانی از ادامه** - دانلودهای قطع شده قابل ادامه هستند
- 🧹 **پاکسازی نام** - پاکسازی خودکار عنوان‌ها برای اسم فایل امن

### دانلودر وب‌سایت (پشتیبان‌گیری)
- 🌐 **آینه‌سازی کامل** - خزش و پشتیبان‌گیری از کل وب‌سایت
- 📄 **پشتیبان صفحه تکی** - ذخیره صفحه با همه وابستگی‌ها
- 🎯 **پشتیبانی SPA** - مدیریت مسیریابی مبتنی بر هش (#!/ و #!)
- 🖼️ **بازنویسی دارایی** - بازنویسی خودکار آدرس برای مرور آفلاین
- 🚀 **خزش همزمان** - کارگرهای قابل تنظیم برای صفحات و دارایی‌ها
- 💾 **خزش قابل ادامه** - ذخیره و ادامه پشتیبان‌گیری قطع شده
- 🎨 **پردازش CSS/JS** - بازنویسی آدرس در استایل‌شیت و اسکریپت
- 🖼️ **پشتیبانی Iframe** - دانلود محتوای iframe به صورت بازگشتی
- ⚡ **محدودیت نرخ** - کنترل درخواست به ازای هر دامنه (قابل تنظیم)
- 🗜️ **فشرده‌سازی** - مینی‌فای کردن HTML برای حجم کمتر
- 🔄 **پشتیبانی متا-رفرش** - دنبال کردن ریدایرکت‌های متا-رفرش

### پشتیبانی Metalink (RFC 5854)
- 📦 **پشتیبانی نسخه ۳ و ۴** - انطباق کامل با مشخصات Metalink
- 🔄 **انتخاب آینه** - انتخاب خودکار آینه بر اساس اولویت
- ✅ **تأیید یکپارچگی** - اعتبارسنجی جمع‌بازی داخلی
- 📊 **اطلاعات تکه‌ها** - تقسیم‌بندی فایل با تأیید هش

### رابط RPC
- 🔌 **API JSON-RPC** - قابلیت کنترل کامل از راه دور
- 🌐 **نقاط پایانی REST** - نقاط HTTP برای وضعیت و کنترل
- 📊 **مانیتورینگ بی‌درنگ** - پیشرفت و آمار دانلود
- 🎮 **کنترل پویا** - توقف، ادامه، محدودیت سرعت از طریق API
- 📋 **مدیریت تسک** - اضافه، حذف و نظارت بر تسک‌های دانلود

### پشتیبانی SFTP
- 🔑 **احراز هویت کلید SSH** - پشتیبانی RSA، ECDSA، Ed25519
- 🔐 **احراز هویت رمز عبور** - با بازگشت به کلیدها
- 📁 **قابلیت کامل ادامه** - قطع و ادامه انتقال‌های SFTP
- ⏱️ **تایم‌اوت قابل تنظیم** - تایم‌اوت اتصال و عملیات

## 🚀 شروع سریع

### 📺 دانلود استریم HLS (جدید)

استریم‌های زنده رو به راحتی دانلود کن:

```bash
# دانلود استریم با FFmpeg (پیشنهادی)
./had -hls https://example.com/stream.m3u8 -o ./videos

# دانلود استریم (خودش FFmpeg رو تشخیص میده، اگر نباشه از گو استفاده میکنه)
./had -hls https://example.com/playlist.m3u8 -t 8

# دانلود از استریم زنده
./had -hls "https://example.com/live/index.m3u8" -o ./recordings
```

### 📋 سیستم صف اولویت‌دار (جدید)

دانلودها رو با اولویت مدیریت کن:

```bash
# دانلود از فایل صف (عدد بیشتر = اولویت بالاتر)
./had -queue queue.txt

# فرمت فایل صف:
# https://example.com/important.zip 100
# https://example.com/normal.zip 50
# https://example.com/low.zip 10

# اضافه کردن اولویت به دانلود تکی
./had -priority 100 https://example.com/urgent-file.zip
```

### ⏰ زمان‌بندی پهنای باند (جدید)

دانلود رو توی بازه‌های زمانی خاص برنامه‌ریزی کن:

```bash
# دانلود فقط بین ۰۲:۰۰ تا ۰۶:۰۰
./had -schedule-from 02:00 -schedule-to 06:00 https://example.com/large-file.zip

# ترکیب با محدودیت سرعت توی بازه زمانی
./had -schedule-from 23:00 -schedule-to 07:00 -max-speed 1048576 https://example.com/file.zip
```

### 📢 اعلان‌ها (جدید)

وقتی دانلود تموم شد بهت خبر بده:

```bash
# اعلان تلگرام
./had -notify-telegram 123456789 -notify-telegram-bot "توکن_ربات_شما" https://example.com/file.zip

# هوک دیسکورد
./had -notify-discord "https://discord.com/api/webhooks/..." https://example.com/file.zip

# اعلان دسکتاپ (لینوکس/مک/ویندوز)
./had -notify-desktop https://example.com/file.zip

# چند اعلان همزمان
./had -notify-telegram ... -notify-discord ... -notify-desktop https://example.com/file.zip
```

### 🗜️ پردازش پس از دانلود (جدید)

بعد از تموم شدن دانلود، عملیات خودکار انجام بده:

```bash
# اکسترکت خودکار آرشیو بعد از دانلود
./had -post-extract https://example.com/archive.zip

# انتقال به دایرکتوری خاص
./had -post-move /completed https://example.com/file.zip

# تغییر اسم با الگو (جای‌گیرنده‌های {name} و {time})
./had -post-rename "{name}_{time}.zip" https://example.com/file.zip

# زنجیره‌ای از پردازش‌ها
./had -post-extract -post-move /processed -post-rename "dl_{time}" https://example.com/archive.zip
```

### 🪞 انتخاب هوشمند آینه (جدید)

سریع‌ترین آینه رو به طور خودکار انتخاب کن:

```bash
# انتخاب خودکار سریع‌ترین آینه
./had -auto-mirror -mirrors "https://mirror1.com/file.zip,https://mirror2.com/file.zip" https://primary.com/file.zip

# همه آینه‌ها رو پینگ میکنه و کم‌تاخیرترین رو انتخاب میکنه
```

### پروکسی ضبط MITM

لینک‌های دانلود رو حین مرور ضبط کن:

```bash
# شروع پروکسی روی پورت ۸۰۸۵
./had -capture-proxy :8085 -capture-types video,music

# ضبط با پسوندهای سفارشی
./had -capture-proxy :9090 -capture-types video,archive -capture-exts .webm,.mka

# دانلود خودکار فایل‌های ضبط شده
./had -capture-proxy :8085 -capture-auto -capture-output ./downloads

# فیلتر بر اساس دامنه و اطمینان
./had -capture-proxy :8085 -filter-domain example.com -capture-confidence 50

# فعال کردن اسکن بدنه (پیدا کردن لینک‌های مخفی)
./had -capture-proxy :8085 -capture-body -verbose

# فقط نصب گواهی
./had -install-cert
```

### افزونه مرورگر (جدید)

هد یه افزونه کاملاً بازطراحی‌شده داره که مدیریت پروکسی و کوکی‌ها رو خیلی راحت‌تر میکنه.

#### امکانات
- 🍪 **مدیریت کوکی** - دیدن، ویرایش، حذف کوکی‌های سایت فعلی
- 📋 **واردات/صادرات** - خروجی کوکی به صورت هدر، JSON یا نت‌اسکیپ
- ⚡ **پریست‌های سریع** - تنظیمات یک‌کلیک برای پروکسی‌های رایج
- 🏃 **بازگردانی خودکار** - پروکسی با هر بار اجرای مرورگر فعال میشه
- 🔍 **جستجو و فیلتر** - پیدا کردن کوکی با اسم یا مقدار

#### نصب
۱. باز کن `chrome://extensions` (کرومیوم) یا `about:debugging` (فایرفاکس)
۲. حالت توسعه‌دهنده رو فعال کن
۳. بارگذاری از پوشه `./extensions-had/`

### دانلود از JSON ضبط شده

بعد از ضبط لینک‌ها، همه رو با یه دستور دانلود کن:

```bash
# دانلود همه فایل‌های ضبط شده
./had -download-json captured_links.json

# خروجی سفارشی با دانلود همزمان
./had -download-json captured_links.json -o ./videos -u 5

# کارایی بالا (۸ نخ برای هر فایل، ۴ دانلود همزمان)
./had -download-json captured_links.json -t 8 -u 4
```

### دانلود‌های پایه

```bash
# دانلود یه فایل
./had https://example.com/file.zip

# دانلود با ۱۶ نخ
./had -t 16 https://example.com/large-file.zip

# دانلود چند فایل
./had https://example.com/file1.zip https://example.com/file2.zip

# دانلود از لیست فایل
./had -f urls.txt

# دانلود با محدودیت سرعت (۱ مگابایت بر ثانیه)
./had -max-speed 1048576 https://example.com/file.zip

# دانلود با بررسی جمع‌بازی
./had -checksum-sha256 abc123... https://example.com/file.zip

# دانلود با هدرهای سفارشی
./had -H "Authorization: Bearer token123" https://example.com/file.zip
```

### پشتیبان‌گیری از وب‌سایت

```bash
# پشتیبان کامل از سایت
./had web -url https://example.com -mode full

# پشتیبان کامل در دایرکتوری خاص
./had web -url https://example.com -mode full -output ./backup

# پشتیبان صفحه تکی با همه دارایی‌ها
./had web -url https://example.com/about -mode single -download-external

# پشتیبان با دارایی‌های CDN خارجی
```

## 🔧 نصب دستی افزونه و تنظیم گواهی

### افزونه ضبط (extension-had)

هد یه افزونه مرورگر کاملاً بازطراحی‌شده داره که مدیریت پروکسی و کوکی‌ها رو خیلی راحت‌تر میکنه. فایل‌های افزونه توی پوشه `extensions-had/` هستن.

#### نصب دستی

**برای کروم / بریو / اج (کرومیوم‌بیس):**

۱. مرورگر رو باز کن و برو به `chrome://extensions`
۲. **"حالت توسعه‌دهنده"** رو فعال کن (توی گوشه بالا سمت راست)
۳. روی دکمه **"بارگذاری بدون بسته"** کلیک کن
۴. به پوشه افزونه هد برو: `./extensions-had`
۵. پوشه رو انتخاب کن و روی **"انتخاب پوشه"** کلیک کن
۶. افزونه هد توی لیست افزونه‌ها ظاهر میشه

**برای فایرفاکس:**

۱. فایرفاکس رو باز کن و برو به `about:debugging`
۲. توی نوار کناری سمت چپ روی **"This Firefox"** کلیک کن
۳. روی دکمه **"Load Temporary Add-on"** کلیک کن
۴. به پوشه `./extensions-had/` برو
۵. فایل `manifest.json` رو انتخاب کن
۶. **نکته:** فایرفاکس افزونه‌ها رو موقتی بارگذاری میکنه. برای نصب دائمی باید افزونه رو بسته‌بندی و امضا کنی

#### امکانات افزونه (جدید)

۱. **تب مدیریت پروکسی**
   - پریست‌های سریع برای تنظیمات رایج
   - تنظیم هاست، پورت و پروتکل
   - دکمه تست اتصال
   - دکمه‌های فعال/غیرفعال
   - نمایش وضعیت با زمان اجرا

۲. **تب مدیریت کوکی**
   - دیدن همه کوکی‌های سایت فعلی
   - ویرایش مقادیر کوکی
   - حذف کوکی تکی
   - کپی کوکی در کلیپ‌بورد
   - خروجی به صورت هدر، JSON یا نت‌اسکیپ
   - ورودی از JSON، نت‌اسکیپ یا رشته هدر
   - جستجو و فیلتر کوکی
   - پاک کردن همه کوکی‌های سایت

۳. **تب تنظیمات**
   - بازگردانی خودکار پروکسی با شروع مرورگر
   - مدیریت لیست بای‌پس

### نصب گواهی CA

برای رهگیری HTTPS، باید گواهی CA هد رو روی سیستم نصب کنی.

#### نصب خودکار (پیشنهادی)

```bash
# نصب خودکار گواهی
./had -install-cert

# یا با پروکسی ضبط اجرا کن (خودکار نصب میکنه)
./had -capture-proxy :8085
```

#### نصب دستی

اگه نصب خودکار کار نکرد، این مراحل رو دنبال کن:

**مرحله ۱: تولید گواهی**

```bash
# یک بار هد رو با پروکسی ضبط اجرا کن تا گواهی ساخته بشه
./had -capture-proxy :8085
# گواهی به اسم 'had.crt' توی دایرکتوری فعلی ساخته میشه
# برای توقف Ctrl+C رو بزن
```

**مرحله ۲: نصب گواهی روی سیستم‌عامل**

**ویندوز:**
۱. روی فایل `had.crt` دابل‌کلیک کن
۲. روی **"Install Certificate"** کلیک کن
۳. **"Local Machine"** رو انتخاب کن (نیاز به دسترسی ادمین داره)
۴. **"Place all certificates in the following store"** رو انتخاب کن
۵. روی **"Browse"** کلیک کن و **"Trusted Root Certification Authorities"** رو انتخاب کن
۶. **"OK"** → **"Next"** → **"Finish"** رو بزن
۷. مرورگر رو ریستارت کن

**لینوکس (اوبونتو/دبیان):**

```bash
# کپی گواهی در فروشگاه اعتماد سیستم
sudo cp had.crt /usr/local/share/ca-certificates/had.crt
sudo update-ca-certificates

# برای فایرفاکس (دستی)
# برو به about:preferences#privacy → View Certificates → Import → had.crt رو انتخاب کن
# "Trust this CA to identify websites" رو تیک بزن
```

**لینوکس (RHEL/فدورا):**

```bash
sudo cp had.crt /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust
```

**مک:**

```bash
# اضافه به کی‌چین سیستم
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain had.crt

# یا دابل‌کلیک روی had.crt → Add to Keychain → Trust → Always Trust
```

**مرحله ۳: بررسی نصب**

```bash
# شروع پروکسی ضبط
./had -capture-proxy :8085

# مرورگر رو روی localhost:8085 به عنوان پروکسی HTTP/HTTPS تنظیم کن
# برو به https://example.com - نباید هشدار گواهی ببینی
```

### عیب‌یابی گواهی

| مشکل | راه‌حل |
|---------|----------|
| هشدار گواهی در مرورگر | گواهی رو به عنوان Trusted Root دوباره نصب کن |
| افزونه ضبط نمیکنه | تنظیمات پروکسی رو چک کن (localhost:8085) |
| "ERR_PROXY_CONNECTION_FAILED" | مطمئن شو هد با `-capture-proxy` اجرا شده |
| فایرفاکس "Connection not secure" نشون میده | گواهی `had.crt` رو دستی به فروشگاه فایرفاکس اضافه کن |
| نصب خودکار خطا میده | با دسترسی ادمین/روت اجرا کن یا از روش دستی استفاده کن |

## 📊 نکات عملکرد

۱. **برای فایل‌های بزرگ (۱GB+):** از `-t` با ۸ تا ۱۶ نخ استفاده کن
۲. **برای فایل‌های کوچک زیاد:** از `-u` برای افزایش دانلود همزمان استفاده کن (۱۰ تا ۲۰)
۳. **برای اتصالات کند:** نخ‌ها رو به ۲ تا ۴ کاهش بده و تایم‌اوت رو به ۶۰ ثانیه برسان
۴. **برای پروکسی ضبط:** از `-capture-confidence 30` برای تعادل بین دقت و سرعت استفاده کن
۵. **برای دانلود دسته‌ای از JSON:** از `-u 5` و `-t auto` استفاده کن (خودکار بر اساس حجم تنظیم میشه)
۶. **برای پشتیبان وب:** اول با `-mode single` تست کن، بعد `-mode full`
۷. **برای سایت‌های با محدودیت نرخ:** از `-rate-limit` برای جلوگیری از بلاک شدن استفاده کن (۵ تا ۱۰ req/s)
۸. **برای اتصالات با پهنای باند بالا:** نخ‌ها رو به ۳۲ تا ۶۴ برسون برای حداکثر سرعت
۹. **برای فضای دیسک محدود:** `-disk-cache` رو به ۸ مگابایت یا کمتر کاهش بده
۱۰. **برای دانلود همزمان زیاد:** از `-u` با ۵ تا ۱۰ برای جلوگیری از محدودیت اتصال استفاده کن
۱۱. **برای انتقال SFTP:** به جای رمز عبور از کلید SSH استفاده کن برای عملکرد بهتر
۱۲. **برای دانلود Metalink:** بذار هد خودش بهترین آینه‌ها رو انتخاب کنه
۱۳. **برای استریم HLS:** FFmpeg نصب باشه برای بهترین عملکرد
۱۴. **برای دانلود زمان‌بندی شده:** از `-schedule-from` و `-schedule-to` برای جلوگیری از ساعات اوج استفاده کن
۱۵. **برای پردازش پس از دانلود:** دستورات رو با `-post-extract` و `-post-move` زنجیره کن

## 🔧 استفاده پیشرفته

### اجرا به عنوان دیمون (لینوکس)

```bash
# شروع دیمون
./had -daemon -o /downloads https://example.com/bigfile.zip

# بررسی وضعیت
cat /tmp/had.pid

# توقف دیمون
kill $(cat /tmp/had.pid)

# سرویس systemd
sudo cat > /etc/systemd/system/had.service << EOF
[Unit]
Description=سرویس دانلودر هد
After=network.target

[Service]
Type=simple
User=downloader
ExecStart=/usr/local/bin/had -daemon -o /downloads -rpc
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable had
sudo systemctl start had
```

### استفاده از متغیرهای محیطی

```bash
# تنظیم پروکسی از طریق محیط
export HTTP_PROXY=http://proxy:8080
export HTTPS_PROXY=http://proxy:8080
export NO_PROXY=localhost,127.0.0.1

# اجرا با محیط
./had https://example.com/file.zip
```

### ترکیب با ابزارهای دیگر

```bash
# دانلود و اکسترکت
./had https://example.com/archive.zip && unzip archive.zip

# دانلود و بررسی امضا
./had https://example.com/file.iso && sha256sum -c file.iso.sha256# دانلود لیست از خروجی برنامه دیگه
cat urls.txt | xargs -n1 ./had

# دانلود زمان‌بندی شده با cron
0 2 * * * /usr/local/bin/had https://example.com/daily-backup.zip -o /backups
```

### مثال هدرهای سفارشی

```bash
# چند هدر سفارشی
./had -H "Authorization: Bearer token123" -H "X-Custom-Header: value" https://api.example.com/file.zip

# تغییر User-Agent
./had -H "User-Agent: MyCustomBot/1.0" https://example.com/file.zip

# هدر Referer
./had -H "Referer: https://google.com" https://example.com/file.zip
```

### پروکسی ضبط با هدرهای سفارشی

```bash
# اضافه کردن هدر احراز هویت به پروکسی ضبط
./had -capture-proxy :8085 -capture-header "Authorization: Bearer token123" -capture-header "X-API-Key: abc123"

# عبور کوکی از پروکسی
./had -capture-proxy :8085 -capture-cookie "sessionid=abc123; user=test"
```

### گردش کار کامل خودکار (جدید)

```bash
# دانلود از صف با زمان‌بندی، اعلان و پردازش پس از دانلود
./had \
  -queue queue.txt \
  -schedule-from 00:00 \
  -schedule-to 06:00 \
  -max-speed 1048576 \
  -post-extract \
  -post-move /media/completed \
  -post-rename "{name}_{time}" \
  -notify-telegram 123456789 \
  -notify-telegram-bot "توکن_ربات_شما" \
  -notify-desktop
```

## 🔒 نکته امنیتی

پروکسی ضبط از گواهی CA خودامضا برای رهگیری ترافیک HTTPS استفاده میکنه. این گواهی باید توسط سیستم شما برای کار کردن رهگیری HTTPS معتبر شناخته بشه. فلگ `-install-cert` سعی میکنه خودکار نصب کنه، اما ممکنه بسته به دسترسی‌های سیستم نیاز به نصب دستی داشته باشی.

**مهم:** فقط از این ابزار در شبکه‌ها و وب‌سایت‌هایی استفاده کن که مالکش هستی یا اجازه تست داری. رهگیری ترافیک HTTPS بدون مجوز ممکنه قوانین یا مقررات رو نقض کنه.
