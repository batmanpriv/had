## 🎉 نسخه ۳.۶.۰ چی داره؟

نسخه ۳.۶.۰ هَد یه سری قابلیت جدید و خفن داره که کار باهاش رو حسابی راحت‌تر کرده. بیا ببینیم چی اضافه شده:

| قابلیت | توضیح |
|--------|-------|
| 🖥️ **رابط کاربری وب جدید** | یه داشبورد گرافیکی کامل برای مدیریت دانلودها، آمار، کنسول و تنظیمات (برای موبایل هم بهینه‌ست) |
| 🔄 **بروزرسانی خودکار وب‌یوآی** | همه چیز لحظه‌ای بروز میشه، نیازی به رفرش دستی نیست |
| 📡 **استریم زنده لاگ** | لاگ‌های هَد رو مستقیم توی مرورگر می‌بینی با Server‑Sent Events |
| 🧠 **پروکسی ضبط هوشمندتر** | امتیازدهی بهتر، اسکن بدنه، استخراج لینک‌های مخفی |
| 📺 **پخش زنده HLS** | دانلود استریم‌های زنده با FFmpeg یا خود گو |
| 📋 **سیستم صف اولویت‌دار** | دانلودها رو بر اساس اولویت مرتب کن (عدد بیشتر = اولویت بالاتر) |
| ⏰ **زمان‌بندی پهنای باند** | محدودیت سرعت روز/شب یا بازه‌های زمانی خاص |
| 📢 **اعلان‌های چندکاناله** | تلگرام، دیسکورد، نوتیفیکیشن دسکتاپ |
| 🗜️ **پردازش پس از دانلود** | اکسترکت خودکار، تغییر اسم، جابجایی فایل |
| 🪞 **انتخاب هوشمند آینه** | سریع‌ترین آینه رو با پینگ خودکار انتخاب می‌کنه |
| 🍪 **افزونه مرورگر** | مدیریت پروکسی + ویرایش کوکی برای کروم/اج/فایرفاکس |
| 🔐 **نصب خودکار گواهی** | با یه کلیک گواهی CA نصب میشه برای رهگیری HTTPS |
| 🧩 **حذف تکراری‌ها** | تشخیص و فیلتر هوشمند لینک‌های تکراری |
| 🎯 **بهینه‌سازی نخ بر اساس حجم** | تعداد نخ‌ها رو بر اساس حجم فایل تنظیم می‌کنه |

## 🚀 شروع سریع

### ۱. دانلود ساده – یک فایل

```bash
./had https://example.com/file.zip
```

**چیکار می‌کنه؟**
- فایل `file.zip` رو توی دایرکتوری فعلی دانلود می‌کنه
- از تعداد نخ‌های پیش‌فرض استفاده می‌کنه (تعداد هسته‌های CPU)
- یه نوار پیشرفت نشون میده

### ۲. دانلود با نخ‌های سفارشی

```bash
./had -t 16 https://example.com/large-file.zip
```

**چیکار می‌کنه؟**
- از ۱۶ نخ موازی برای حداکثر سرعت استفاده می‌کنه
- برای فایل‌های بزرگتر از ۱ گیگابایت پیشنهاد میشه

### ۳. دانلود چند فایل

```bash
./had https://example.com/file1.zip https://example.com/file2.zip
```

**چیکار می‌کنه؟**
- هر دو فایل رو همزمان دانلود می‌کنه (تا ۲ تا همزمان به صورت پیش‌فرض)
- پیشرفت ترکیبی نشون میده

### ۴. دانلود از لیست

```bash
./had -f urls.txt
```

**چیکار می‌کنه؟**
- آدرس‌ها رو از `urls.txt` می‌خونه (هر خط یک آدرس)

## 🌐 رابط کاربری وب (جدید)

رابط کاربری وب یه رابط گرافیکی کامل بهت میده تا دانلودها رو مدیریت کنی، آمار ببینی و هَد رو از مرورگر کنترل کنی.

### شروع رابط کاربری وب

```bash
./had -web-ui
```

یا با فرم کوتاه:

```bash
./had webui
```

بعد مرورگرت رو باز کن و برو به:  
👉 **http://localhost:8090**

### تنظیمات رابط کاربری وب

| متغیر محیطی | توضیح | پیش‌فرض |
|-------------|-------|---------|
| `HAD_WEB_ADDR` | آدرس بایند رابط کاربری وب | `:8090` |
| `HAD_RPC_ADDR` | نقطه انتهایی RPC | `http://localhost:6800` |
| `HAD_TOKEN` | توکن اختیاری برای احراز هویت | (هیچ) |

**مثال با تنظیمات سفارشی:**

```bash
HAD_WEB_ADDR=:9000 HAD_TOKEN=secret123 ./had -web-ui
```

### امکانات رابط کاربری وب به تفصیل

#### داشبورد
- **لیست دانلود** – همه دانلودهای فعال رو با اسم فایل، حجم، نوار پیشرفت و سرعت نشون میده
- **پیشرفت تک‌نخ** – وقتی حالت verbose فعال باشه، پیشرفت هر نخ رو نشون میده
- **آمار کلی** – سرعت کل، زمان باقیمونده، زمان اجرا، دانلودهای فعال
- **پیشرفت کلی** – نوار پیشرفت تجمعی برای همه دانلودها
- **دکمه‌های عملیاتی** – توقف همه، ادامه همه، حذف همه

#### افزودن آدرس
- **ورودی آدرس** – چسباندن یک یا چند آدرس (هر خط یک آدرس)
- **نخ‌ها** – تنظیم نخ‌ها برای هر فایل (۱‑۳۲)
- **محدودیت سرعت** – انتخاب از پیش‌تنظیمات یا وارد کردن مقدار دلخواه
- **دایرکتوری خروجی** – مشخص کردن محل ذخیره فایل‌ها
- **چسباندن از کلیپ‌بورد** – چسباندن مستقیم آدرس‌ها از کلیپ‌بورد
- **پیش‌تنظیمات سریع** – آدرس‌های نمونه برای تست

#### اسکرپ
- **ورودی آدرس** – وارد کردن آدرس صفحه وب
- **تشخیص خودکار** – پیدا کردن و دانلود همه فایل‌های مدیا (ویدیو، موسیقی، آرشیو و...)
- **لاگ زنده** – نمایش پیشرفت اسکرپ و لینک‌های پیدا شده

#### جلسات
- **مشاهده جلسات** – لیست همه جلسات ذخیره شده برای ادامه
- **ادامه** – ادامه دانلودهای قطع شده
- **حذف** – حذف فایل‌های جلسه ناخواسته

#### تاریخچه
- **دانلودهای تکمیل شده** – لیست دانلودهای تمام شده با حجم، سرعت، مدت زمان
- **پاک کردن** – حذف همه ورودی‌های تاریخچه

#### کنسول
- **استریم زنده لاگ** – مشاهده لاگ‌های هَد به صورت لحظه‌ای
- **توقف/ادامه** – توقف یا ادامه استریم لاگ
- **پاک کردن** – پاک کردن خروجی کنسول

#### آمار
- **نمودار سرعت** – نمودار تاریخچه سرعت لحظه‌ای (۶۰ ثانیه آخر)
- **آمار** – سرعت، کل دانلود شده، فایل‌های تکمیل شده، دانلودهای فعال، زمان اجرا، زمان باقیمونده
- **پیشرفت کلی** – نوار پیشرفت تجمعی
- **اطلاعات سرور** – نسخه، محدودیت سرعت، حداکثر همزمانی، نخ‌ها، دایرکتوری خروجی، وضعیت توقف

#### ابزارها
- **بازرسی متادیتا** – دریافت اطلاعات فایل، نوع محتوا، حجم، چکسام قبل از دانلود
- **تست سرعت آینه** – تست چندین آینه و رتبه‌بندی بر اساس سرعت و تاخیر
- **بررسی چکسام** – محاسبه و بررسی هش‌های MD5، SHA‑۱، SHA‑۲۵۶
- **زمان‌بندی پهنای باند** – تنظیم محدودیت سرعت روز/شب

#### تنظیمات
- **آدرس RPC** – نقطه انتهایی سرور RPC هَد
- **توکن احراز هویت** – توکن اختیاری برای احراز هویت
- **بروزرسانی خودکار** – فاصله بروزرسانی (۱ ثانیه، ۲ ثانیه، ۵ ثانیه، خاموش)
- **محدودیت سرعت کلی** – تنظیم محدودیت سرعت بر حسب بایت بر ثانیه (۰ = نامحدود)
- **حداکثر دانلود همزمان** – حداکثر تعداد دانلود همزمان
- **نخ‌های هر فایل** – تعداد بخش‌های همزمان برای هر دانلود
- **دایرکتوری خروجی** – مسیر پیش‌فرض ذخیره

### میانبرهای رابط کاربری وب

| میانبر | عملیات |
|--------|---------|
| `Ctrl+K` | فوکوس روی ورودی افزودن آدرس |
| `Ctrl+R` | بروزرسانی داشبورد |

## 🖥️ استفاده از خط فرمان – مثال‌های کامل

### دانلودهای پایه

#### دانلود یک فایل

```bash
./had https://example.com/file.zip
```

**توضیح:**
- فایل `file.zip` رو توی دایرکتوری فعلی دانلود می‌کنه
- از تعداد نخ‌های پیش‌فرض استفاده می‌کنه (تعداد هسته‌های CPU)
- یه نوار پیشرفت با سرعت و زمان باقیمونده نشون میده

#### دانلود با نخ‌های سفارشی

```bash
./had -t 16 https://example.com/large-file.zip
```

**توضیح:**
- از ۱۶ نخ موازی برای حداکثر سرعت استفاده می‌کنه
- برای فایل‌های بزرگتر از ۱ گیگابایت پیشنهاد میشه
- هر نخ یک بخش جداگانه از فایل رو دانلود می‌کنه

#### دانلود چند فایل

```bash
./had https://example.com/file1.zip https://example.com/file2.zip https://example.com/file3.zip
```

**توضیح:**
- هر سه فایل رو همزمان دانلود می‌کنه
- همزمانی پیش‌فرض ۲ هست (از `-u` برای تغییر استفاده کن)
- پیشرفت ترکیبی برای همه دانلودها نشون میده

#### دانلود از لیست فایل

```bash
./had -f urls.txt
```

**توضیح:**
- آدرس‌ها رو از `urls.txt` می‌خونه (هر خط یک آدرس)
- از کامنت‌هایی که با `#` شروع می‌شن پشتیبانی می‌کنه
- مثال `urls.txt`:
  ```text
  # این یک کامنت است
  https://example.com/file1.zip
  https://example.com/file2.zip
  ftp://ftp.example.com/large-file.iso
  ```

#### دانلود با محدودیت سرعت

```bash
./had -max-speed 1048576 https://example.com/file.zip
```

**توضیح:**
- سرعت دانلود رو روی ۱ مگابایت بر ثانیه محدود می‌کنه (۱۰۴۸۵۷۶ بایت بر ثانیه)
- برای اتصالات با پهنای باند محدود مفیده
- از اشباع شدن شبکه توسط هَد جلوگیری می‌کنه

#### دانلود با دایرکتوری خروجی سفارشی

```bash
./had -o ./downloads https://example.com/file.zip
```

**توضیح:**
- فایل رو به جای دایرکتوری فعلی، توی `./downloads/` ذخیره می‌کنه
- اگر دایرکتوری وجود نداشته باشه، می‌سازتش

#### دانلود با خروجی مفصل

```bash
./had -v https://example.com/file.zip
```

**توضیح:**
- پیشرفت دقیق هر نخ رو نشون میده
- نشون میده کدوم بخش‌ها در حال دانلود هستند
- برای دیباگ کردن دانلودهای کند مفیده

### سیستم صف اولویت‌دار

#### ساختن فایل صف

یه فایل `queue.txt` بساز:

```text
# فرمت: آدرس اولویت (عدد بیشتر = زودتر پردازش میشه)
https://example.com/urgent.zip 100
https://example.com/important.zip 75
https://example.com/normal.zip 50
https://example.com/low.zip 10
https://example.com/very-low.zip 1
# کامنت‌ها پشتیبانی می‌شن
```

#### دانلود از صف

```bash
./had -queue queue.txt
```

**توضیح:**
- آدرس‌ها رو به ترتیب اولویت پردازش می‌کنه (بالاترین اولویت اول)
- آدرس با اولویت ۱۰۰ قبل از اولویت ۵۰ دانلود میشه
- مقادیر اولویت می‌تونن هر عدد صحیحی باشن (مثبت یا منفی)
- اعداد اولویت بالاتر زودتر پردازش می‌شن

#### دانلود تکی با اولویت

```bash
./had -priority 100 https://example.com/urgent-file.zip
```

**توضیح:**
- اولویت ۱۰۰ رو به این دانلود اختصاص میده
- وقتی با دانلودهای دیگه توی صف ترکیب بشه مفیده
- اولویت بالاتر = زودتر پردازش میشه

#### صف با پردازش پس از دانلود

```bash
./had -queue queue.txt -post-extract -post-move /processed
```

**توضیح:**
- همه آیتم‌های صف رو به ترتیب اولویت دانلود می‌کنه
- آرشیوها رو خودکار اکسترکت می‌کنه
- فایل‌های تکمیل شده رو به `/processed` منتقل می‌کنه

### افزونه مرورگر

#### نصب

**برای کروم / بریو / اج (کرومیوم‌بیس):**

۱. مرورگرت رو باز کن و برو به `chrome://extensions`
۲. **"حالت توسعه‌دهنده"** رو فعال کن
۳. روی دکمه **"بارگذاری بدون بسته"** کلیک کن
۴. به پوشه افزونه هَد برو: `./extensions-had`
۵. پوشه رو انتخاب کن و روی **"انتخاب پوشه"** کلیک کن

**برای فایرفاکس:**

۱. فایرفاکس رو باز کن و برو به `about:debugging`
۲. روی **"This Firefox"** توی نوار کناری کلیک کن
۳. روی دکمه **"Load Temporary Add-on"** کلیک کن
۴. به پوشه `./extensions-had/` برو
۵. فایل `manifest.json` رو انتخاب کن

#### امکانات افزونه

**تب مدیریت پروکسی:**
- **پیش‌تنظیمات سریع** – تنظیمات یک‌کلیک برای پروکسی‌های رایج (HAD:8085، HTTP:8080، SOCKS5:1080، TOR:9050)
- **تنظیم دستی** – تنظیم هاست، پورت و پروتکل
- **تست اتصال** – بررسی اینکه پروکسی قابل دسترس هست یا نه
- **فعال/غیرفعال** – فعال یا غیرفعال کردن پروکسی
- **نمایش وضعیت** – زمان اجرا و وضعیت فعال رو نشون میده

**تب مدیریت کوکی:**
- **مشاهده کوکی** – دیدن همه کوکی‌های سایت فعلی
- **جستجو** – فیلتر کردن کوکی‌ها بر اساس اسم یا مقدار
- **ویرایش** – تغییر مقادیر کوکی به صورت مستقیم
- **حذف** – حذف کوکی‌های تکی
- **کپی** – کپی کردن کوکی‌ها در کلیپ‌بورد
- **خروجی** – خروجی به صورت هدر، JSON یا نت‌اسکیپ
- **ورودی** – ورودی از JSON، نت‌اسکیپ یا رشته هدر
- **پاک کردن همه** – حذف همه کوکی‌های سایت فعلی

**تب تنظیمات:**
- **بازگردانی خودکار** – بازگردانی خودکار پروکسی با شروع مرورگر
- **لیست بای‌پس** – میزبان‌هایی که پروکسی رو رد می‌شن (هر خط یک میزبان)
- **ذخیره لیست بای‌پس** – ذخیره تغییرات لیست بای‌پس

#### راه‌اندازی سریع پروکسی

۱. روی آیکون افزونه هَد توی نوار ابزار مرورگر کلیک کن
۲. روی یکی از دکمه‌های پیش‌تنظیم کلیک کن (HAD:8085، HTTP:8080، SOCKS5:1080، TOR:9050)
۳. روی **"ACTIVATE"** کلیک کن تا پروکسی فعال بشه
۴. نوار وضعیت "ACTIVE" رو با زمان اجرا نشون میده

#### مدیریت کوکی

۱. به هر سایتی برو
۲. روی آیکون افزونه هَد کلیک کن
۳. به تب **"COOKIES"** برو
۴. همه کوکی‌های سایت فعلی رو می‌بینی
۵. روی مقدار کوکی کلیک کن تا کامل باز بشه
۶. از دکمه‌های **EDIT**، **DELETE** یا **COPY** استفاده کن
۷. کوکی‌ها رو به صورت هدر، JSON یا نت‌اسکیپ صادر کن
۸. کوکی‌ها رو از JSON، نت‌اسکیپ یا رشته هدر وارد کن

### حالت دیمون

#### شروع دیمون

```bash
./had -daemon -o /downloads https://example.com/bigfile.zip
```

cat /tmp/had.pid

- برای بررسی اینکه دیمون در حال اجراست استفاده می‌کنن

```bash
kill $(cat /tmp/had.pid)
```

**توضیح:**
- فرآیند دیمون رو متوقف می‌کنه
- از PID فایل PID استفاده می‌کنه

#### سرویس Systemd

یه فایل `/etc/systemd/system/had.service` بساز:

```text
[Unit]
Description=سرویس دانلودر هَد
After=network.target

[Service]
Type=simple
User=downloader
ExecStart=/usr/local/bin/had -daemon -o /downloads -rpc
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

بعد فعال و شروع کن:

```bash
sudo systemctl enable had
sudo systemctl start had
```

### سوالات HLS / استریم

| سوال | پاسخ |
|------|------|
| **HLS چیه؟** | HLS (پخش زنده HTTP) یه پروتکل استریمینگ هست که توسط اپل توسعه داده شده. بسیاری از پلتفرم‌های ویدیو (یوتیوب زنده، توئیچ، هولو، نتفلیکس و...) برای ارائه محتوای ویدیویی ازش استفاده می‌کنن. HLS از **پلی‌لیست‌های M3U8** استفاده می‌کنه که به **سگمنت‌های TS** اشاره می‌کنن. |
| **چطور یه استریم HLS دانلود کنم؟** | از `-hls` با آدرس پلی‌لیست M3U8 استفاده کن:<br>`./had -hls https://example.com/stream.m3u8`<br>هَد همه سگمنت‌ها رو دانلود و توی یه فایل ترکیب می‌کنه. |
| **به FFmpeg نیاز دارم؟** | نه، هَد یه **پشتیبان خالص گو** داره. اما:<br>• **با FFmpeg** → سریع‌تر، خروجی MP4 تولید می‌کنه<br>• **بدون FFmpeg** → کندتر، خروجی TS تولید می‌کنه<br>هَد FFmpeg رو خودکار تشخیص میده و با ظرافت به پشتیبان برمی‌گرده. |
| **می‌تونم استریم‌های زنده رو دانلود کنم؟** | بله! هَد از استریم‌های زنده HLS پشتیبانی می‌کنه. دانلود تا زمانی که سگمنت‌های جدید در دسترس بشن ادامه پیدا می‌کنه. دانلود تا زمانی که متوقفش کنی (Ctrl+C) یا استریم تموم بشه، ادامه داره. |
| **چرا دانلود HLS من fail میشه؟** | مشکلات رایج:<br>• **آدرس M3U8 قابل دسترس نیست** → بررسی کن توی مرورگر کار می‌کنه<br>• **احراز هویت لازمه** → از کوکی یا هدر استفاده کن<br>• **پلی‌لیست نامعتبر** → M3U8 ممکنه خالی یا خراب باشه<br>• **محدودیت نرخ** → سرور ممکنه درخواست‌های متعدد رو مسدود کنه<br>• **مشکلات شبکه** → اتصالت رو چک کن<br>برای دیدن اینکه چه اتفاقی می‌افته، از `-v` برای خروجی دیباگ استفاده کن. |
| **چطور فرمت خروجی رو مشخص کنم؟** | • **با FFmpeg** → خروجی خودکار MP4 هست<br>• **بدون FFmpeg** → خروجی TS هست<br>می‌تونی پسوند رو بعد از دانلود دستی تغییر بدی، یا از `-post-rename` برای تغییر اسم استفاده کنی. |
| **می‌تونم اسم فایل خروجی رو مشخص کنم؟** | از `-o` با یه اسم فایل (نه فقط دایرکتوری) استفاده کن:<br>`./had -hls https://example.com/stream.m3u8 -o ./videos/my_video.mp4`<br>اگه دایرکتوری مشخص کنی، هَد از اسم فایل توی آدرس استفاده می‌کنه. |
| **می‌تونم دانلود HLS رو ادامه بدم؟** | نه، دانلودهای HLS قابل ادامه نیستن چون سگمنت‌ها یک بار دانلود و ترکیب می‌شن. اما اگه سگمنتی fail بشه، هَد دوباره تلاش می‌کنه (تا `-r` بار). |
| **هَد از DASH (MPD) پشتیبانی می‌کنه؟** | نه هنوز. هَد فعلاً فقط از **HLS (M3U8)** پشتیبانی می‌کنه. پشتیبانی از DASH برای نسخه‌های آینده برنامه‌ریزی شده. |
| **می‌تونم استریم‌های HLS محافظت شده با DRM رو دانلود کنم؟** | نه، هَد نمی‌تونه استریم‌های محافظت شده با DRM (مثل Widevine، FairPlay) رو رمزگشایی کنه. فقط با استریم‌های رمزگذاری نشده یا رمزگذاری شده با AES‑۱۲۸ کار می‌کنه (اگر کلید توی M3U8 موجود باشه). |
| **فرق VOD و HLS زنده چیه؟** | • **VOD (ویدیو درخواستی)** – یه پلی‌لیست کامل با همه سگمنت‌ها، سریع دانلود میشه<br>• **زنده** – پلی‌لیست مدام بروزرسانی میشه، سگمنت‌ها به مرور زمان در دسترس قرار می‌گیرن<br>هَد هر دو رو مدیریت می‌کنه، اما استریم‌های زنده به صبر نیاز دارن چون سگمنت‌ها به صورت لحظه‌ای تولید می‌شن. |

## 🔧 استفاده پیشرفته

### اجرا به عنوان دیمون (لینوکس)

```bash
# شروع دیمون
./had -daemon -o /downloads https://example.com/bigfile.zip

# بررسی وضعیت
cat /tmp/had.pid

# توقف دیمون
kill $(cat /tmp/had.pid)

# سرویس systemd
sudo cat > /etc/systemd/system/had.service << EOF
[Unit]
Description=سرویس دانلودر هَد
After=network.target

[Service]
Type=simple
User=downloader
ExecStart=/usr/local/bin/had -daemon -o /downloads -rpc
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable had
sudo systemctl start had
```

### استفاده از متغیرهای محیطی

```bash
# تنظیم پروکسی از طریق محیط
export HTTP_PROXY=http://proxy:8080
export HTTPS_PROXY=http://proxy:8080
export NO_PROXY=localhost,127.0.0.1

# تنظیم آدرس RPC
export HAD_RPC_ADDR=http://localhost:6800

# تنظیم آدرس رابط کاربری وب
export HAD_WEB_ADDR=:8090

# تنظیم توکن احراز هویت
export HAD_TOKEN=secret123

# اجرا با محیط
./had https://example.com/file.zip
```

### ترکیب با ابزارهای دیگر

```bash
# دانلود و اکسترکت
./had https://example.com/archive.zip && unzip archive.zip

# دانلود و بررسی امضا
./had https://example.com/file.iso && sha256sum -c file.iso.sha256

# دانلود لیست از خروجی برنامه دیگه
cat urls.txt | xargs -n1 ./had

# دانلود زمان‌بندی شده با cron
0 2 * * * /usr/local/bin/had https://example.com/daily-backup.zip -o /backups

# دانلود و انتقال به دایرکتوری خاص
./had -post-move /media/videos https://example.com/video.mp4
```

## 🔒 نکته امنیتی

پروکسی ضبط از گواهی CA خودامضا برای رهگیری ترافیک HTTPS استفاده می‌کنه. این گواهی باید توسط سیستم شما برای کار کردن رهگیری HTTPS معتبر شناخته بشه. پرچم `-install-cert` سعی می‌کنه خودکار نصب کنه، اما ممکنه بسته به دسترسی‌های سیستم نیاز به نصب دستی داشته باشی.

**مهم:** فقط از این ابزار در شبکه‌ها و وب‌سایت‌هایی استفاده کن که مالکش هستی یا اجازه تست داری. رهگیری ترافیک HTTPS بدون مجوز ممکنه قوانین یا مقررات رو نقض کنه.

### عیب‌یابی نصب گواهی

| مشکل | راه‌حل |
|------|-------|
| **هشدار گواهی در مرورگر** | گواهی رو به عنوان Trusted Root دوباره نصب کن |
| **افزونه ضبط نمی‌کنه** | تنظیمات پروکسی رو چک کن (localhost:8085) |
| **"ERR_PROXY_CONNECTION_FAILED"** | مطمئن شو هَد با `-capture-proxy` اجرا شده |
| **فایرفاکس "Connection not secure" نشون میده** | گواهی `had.crt` رو دستی به فروشگاه فایرفاکس اضافه کن |
| **نصب خودکار خطا میده** | با دسترسی ادمین/روت اجرا کن یا از روش دستی استفاده کن |

- FFmpeg (اختیاری، برای دانلود HLS – در صورت نبود به خالص گو برمی‌گرده)

### دستورات ساخت

```bash
# لینوکس/مک
go build -o had main.go

# ویندوز
GOOS=windows GOARCH=amd64 go build -o had.exe main.go

# لینوکس ARM64
GOOS=linux GOARCH=arm64 go build -o had-linux-arm64 main.go

# با بهینه‌سازی (فایل کوچیک‌تر)
go build -ldflags="-s -w" -o had main.go

# کراس‌کامپایل برای همه پلتفرم‌ها
GOOS=linux GOARCH=amd64 go build -o had-linux-amd64 main.go
GOOS=linux GOARCH=386 go build -o had-linux-386 main.go
GOOS=linux GOARCH=arm64 go build -o had-linux-arm64 main.go
GOOS=windows GOARCH=amd64 go build -o had-windows-amd64.exe main.go
GOOS=windows GOARCH=386 go build -o had-windows-386.exe main.go
GOOS=darwin GOARCH=amd64 go build -o had-darwin-amd64 main.go
GOOS=darwin GOARCH=arm64 go build -o had-darwin-arm64 main.go
```
